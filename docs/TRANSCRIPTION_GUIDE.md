# Transcription guide

References are what a careful person would type after listening, written normally.

- **Words**: exactly what was said, in order. Remove only filler sounds ("um", "uh") and false starts that are immediately repeated.
- **Self-corrections**: transcribe what was said, including the correction cue. Whether an engine or app applies corrections is measured elsewhere.
- **Numbers**: write them as a person would type them in that context ("3 pm", "$20", "2026", "seven people").
- **Names and terms**: correct spelling as the speaker intends it; check with the speaker.
- **Punctuation and case**: normal written punctuation and capitalization; formatted scoring depends on it.
- **Spoken punctuation**: if the speaker says "comma", the reference contains a comma, not the word.
- **Inaudible audio**: if a word cannot be determined, mark the clip for review rather than guessing.

Each reference is reviewed by a second person. Corrections are logged with the date and reason.
