# data/

Nothing in this folder is committed except this file. The in-house English
recordings, their references and the tested systems' transcripts are released
at https://huggingface.co/datasets/hey-lemon/streaming-dictation-asr (CC BY 4.0);
put them here to rerun the benchmark on them. The public language clips come
from their source datasets (see docs/DATASET.md), and EARS and VOiCES go in
data-external/ (see data-external/README.md).

```
data/
  <set>/           audio + transcripts.tsv, one folder per set in config/sets.json
  manifest.tsv     generated by `npm run manifest`
```

## transcripts.tsv

Tab-separated, one row per clip, header first.

| Column | Required | Notes |
|---|---|---|
| file | yes | WAV file name in the same folder (16 kHz mono) |
| reference | yes | The correct transcript as normally written. Empty for non-speech clips. |
| speaker | strongly recommended | Stable speaker id. Needed for honest confidence intervals. |
| gender | no | |
| dialect | no | |
| source_id | no | Id in the source dataset |

## Adding a set

1. Add it to `config/sets.json` with its language, condition and source.
2. Put the audio and `transcripts.tsv` in `data/<id>/`.
3. Run `npm run manifest`.

To import sets from an existing folder with a `manifest.csv`, use
`npm run import -- --from <folder>`.
